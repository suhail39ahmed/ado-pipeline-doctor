# Demo recording notes

## What to capture (60–90s)

1. Open terminal in repo root.
2. Run the primary quickstart command from README.
3. Show success output (JSON / HTML path / generated files).
4. Optional: open a second terminal to show `--help` or a second tool.

## Assets to drop in

- `assets/demo.gif` — screen recording of the happy path
- `assets/architecture.png` — export the ASCII architecture from README (draw.io / Excalidraw)

## Tools

- asciinema + `agg` for GIF, or Kap / Peek
- Keep terminal font large; no secrets on screen
